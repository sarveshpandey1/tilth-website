03The point isn't the link — it's the convention.

UTMs only work if everyone tags the same way every time. Pick one spelling and case for each source and medium and never deviate; facebook / cpc and FB / CPC become two different sources in GA4 and quietly split your data. Agree the naming rules once, then use this builder to enforce them.
